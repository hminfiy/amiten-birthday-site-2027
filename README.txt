# AMI BIRTHDAY 2027 — teaser site

## ローカルで確認する方法
1. `index.html` をダブルクリックしてブラウザで開く。
2. `style.css` で色・レイアウトを調整する。
3. `script.js` でカウントダウンの日付や動きを調整する。

## 差し替えポイント
- キャラクター部分は、実際のあみちゃんのイラスト画像に差し替え可能。
- `PHOTO 01〜03` は写真素材に置き換え可能。
- 会場や企画情報は `index.html` の INFORMATION セクションを編集する。
- Google Fontsを使用しているため、公開時にネット接続があると指定フォントが読み込まれる。
